## Bilan des commandes Git

- `git status` m’a permis de vérifier quels fichiers étaient modifiés et lesquels étaient préparés pour le prochain commit.
- `git remote -v` m’a permis de vérifier que le dépôt distant `origin` pointait vers le bon dépôt GitHub.
- `git log --oneline --graph --all` m’a permis de visualiser l’historique des commits et de suivre la fusion des branches.
